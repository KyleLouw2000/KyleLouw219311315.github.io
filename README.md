# RIDEConnect – Agile Project Portfolio

## Project Introduction

RideConnect is a carpooling application designed to help students and commuters find shared transport. The purpose of the application is to connect drivers and passengers travelling in similar directions, making commuting more convenient and helping reduce traffic congestion.

This section of my digital portfolio presents the Agile project management activities completed during the RideConnect project. It includes the Agile Team Charter, User Stories and Tasks, Product Backlog, Sprint Backlog and Agile Logbook.

---

# 2. User Stories and Tasks

## Evidence

For RideConnect, we created user stories to identify the different needs and requirements of the people who would use the application.

The user stories were based on different types of users, including passengers, drivers and administrators. They helped us identify the features that needed to be included in the application.

The following screenshots show our User Stories and Tasks.

![User Stories 1](02a-user-stories.png)

![User Stories 2](02b-user-stories.png)

![User Stories 3](02c-user-stories.png)

![User Stories 4](02d-user-stories.png)

## Reflection

Working on the user stories helped me understand how to identify the requirements of an application from the user's perspective.

For RideConnect, we had to consider what passengers, drivers and administrators would need to do when using the system. For example, passengers need to find available rides, drivers need to manage their rides, and administrators need to manage users and monitor the application.

I learned that user stories make it easier to understand what needs to be developed because they explain the purpose of each feature. Breaking these requirements into smaller tasks also helped us organise the work and understand what needed to be completed.

This activity improved my understanding of user requirements and how they are used when planning a software project.
